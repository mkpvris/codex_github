I. 散逸する単一調和振動子 (0:56–19:04)

I-1. 模型とジャンプ演算子 (0:56–3:32)
動画内容:
・空間依存のない単一の量子力学的調和振動子を例とする。H=ω(a†a+1/2), [a,a†]=1, N=a†a。
・a は消滅演算子、a† は生成演算子。L=a は 1 量子の損失、L=a† は 1 量子の利得、L=N は位相緩和を表す (1:55–2:29)。一般には複数チャネルや高次べきも可能だが、一つずつ調べる (2:34–2:47)。
・純粋減衰では L=√κ a, κ>0 と置く。L が 2 回現れるので散逸項全体の係数は κ になり、κ→0 で散逸がなくなる (3:00–3:32)。
使用式:
  dotρ = -i[H,ρ] + κ(aρa† - (1/2){a†a,ρ}).
文献照合: arXiv v1 §3.5, (3.114)–(3.118), 印刷 p.58。
動画にない補足候補:
・梯子演算子の行列要素 a|n>=√n|n-1>, a†|n>=√(n+1)|n+1> は原文 (3.116)。Pauli 方程式の導出に使う場合は「計算の補足」と明記すればよい。

I-2. Population と Pauli 方程式 (3:41–7:22)
動画内容:
・数基底で p_n(t)=<n|ρ(t)|n>=ρ_nn(t) を population / 占有確率と呼ぶ (3:56–4:38)。
・通常は密度行列全体の方程式だが、この L の選択では対角成分だけの閉じた方程式になる (4:52–5:23)。
  dot p_n = κ[(n+1)p_(n+1)-n p_n].
・κ=0 なら population は変わらない。右辺第1項は n+1→n の流入、第2項は n→n-1 の流出 (5:50–6:19)。
・定常解は dot p_n=0 として求める。κ>0 の唯一の正規化された定常状態は ρ*=|0><0|、p_0=1, p_(n>0)=0 (6:29–7:11)。ブランコが最後に止まることの量子版 (7:15–7:22)。
・7:27–8:04 の質問への回答: H の寄与は対角成分では両側の位相が打ち消し合う。一方、非対角成分はエネルギー差の振動を持つ。
文献照合: (3.124)–(3.127), 印刷 p.59。一般の population と coherence の定義は (3.52)–(3.55), 印刷 p.52。
動画にない計算補足候補:
  <n|aρa†|n>=(n+1)p_(n+1),
  (1/2)<n|{N,ρ}|n>=n p_n,
  <n|[H,ρ]|n>=0。
この導出は動画では式の詳しい計算としては展開していない。上記出典に基づく補足であることを明記。
注意: 対角成分が常に閉じるという一般定理にしてはいけない。この例の L と H に依存した性質である。

I-3. 減衰とエントロピー (8:21–9:06)
動画内容:
・混合状態からでも基底状態に近づくので、最終状態の von Neumann entropy は 0。
・開放部分系は環境とやりとりできるため、部分系の entropy が小さくなることは許される。冷蔵庫を類比に挙げる。
校訂すべき点:
・「任意の初期状態で entropy は単調減少する」と書かない。講師のこの段落の語りは略式だが、19:07–19:26 で非単調な例があるとも注意している。厳密には「純粋な基底状態に緩和するので、最終的にゼロに近づく。途中で単調減少するとは限らない」。
・「閉鎖系の von Neumann entropy は常に増大する」も不正確。ユニタリ発展の下では一定。動画 21:26–21:32 も一定と言っている。
補足の裏付け: 原文 §3.5 最後の “Entropy and stationary states” 段落 (印刷 p.62)、および §3.4 の relaxation の説明 (印刷 p.56; 該当段落は式 (3.85) の後)。
補足例 (動画内で数式としては示されない): 初期状態 |1><1| なら ρ(t)=e^{-κt}|1><1|+(1-e^{-κt})|0><0|。二値 entropy は最初 0 から増え、t=(ln2)/κ で最大、最後に 0。採用するなら「文献の説明を具体化した補足計算」とし出典必須。

I-4. Heisenberg 描像と平均占有数 (9:11–15:03)
動画内容:
・Schrödinger 描像では ρ が時間発展し演算子は固定。Heisenberg 描像では初期 ρ を固定し演算子が変わる (9:11–10:06)。
・随伴 Liouvillian を用いる:
  dO/dt = ℒ†[O] = i[H,O] + Σμ( Lμ† O Lμ - (1/2){Lμ†Lμ,O} ).
・L=√κ a と O=N に適用すると dot N=-κN、従って <N(t)>=e^{-κt}<N(0)> (10:51–11:38)。これも基底状態への減衰を意味する (11:42–11:59)。
・描像の同値性 (12:17–12:55):
  Tr[(e^{tℒ}ρ_0)O] = Tr[ρ_0 e^{tℒ†}O].
・13:24–13:57 の質問: 基底状態のエネルギーは ω/2 でも、占有数 N の期待値は 0。混同しない。
・14:04–15:03 の質問: 超演算子の随伴は、上の trace pairing に関する随伴。trace の巡回性で演算子を移しても導ける。
文献照合: §2.5, (2.98)–(2.103), 印刷 pp.40–41；振動子について (3.122)–(3.123), 印刷 p.59。
校訂注意:
・「散逸項は完全に同じ」という字幕 (12:06) を記号配置まで同じと解釈しない。Schrödinger では LρL†、Heisenberg では L†OL。反交換子に L†L が現れる点は同じ。
・13:12–13:20 で講師は L=a† なら占有数が増えるので省略、とだけ述べる。「符号が変わるだけ」を正確な式にしない。純粋利得 L=√κ a† では d<N>/dt=κ(<N>+1) で、+1 の自発項がある。詳細は動画内では扱わないので省略してよい。
・N(t) を a†(t)a(t) と単純に同一視する議論を追加しない。開放系の双対写像は一般に積を保存しない。これは動画範囲外。

I-5. Pure dephasing / 純粋位相緩和 (15:12–19:04)
動画内容:
・L=√γ N (γ≥0)。a や a† に限定されず、このようなジャンプ演算子も許される (15:12–15:33)。
・数基底で各行列要素は独立な微分方程式に従う (15:48–16:53):
  dotρ_mn = [-iω(m-n) - (γ/2)(m-n)^2] ρ_mn.
・m=n の場合右辺は 0、population は不変 (17:01–17:18)。
・coherence は選んだ基底における非対角成分の名称 (17:18–17:36)。
  ρ_mn(t)=exp[-iω(m-n)t] exp[-γ(m-n)^2t/2] ρ_mn(0).
・位相の振動と振幅の減衰を分けて読む。非対角成分は長時間で消え、密度行列は数基底で対角化される (18:16–18:39)。これは decoherence の toy model。講師は古典性の出現に関係すると述べるが、それだけで全ての古典化を証明した扱いにしない (18:39–19:04)。
文献照合: §3.5, (3.139)–(3.143), 印刷 p.61。
校訂注意: 字幕 17:36–18:01 の exponent で i の符号や (m-n) の平方が欠落している。上の照合済み式を使う。
動画にない計算補足候補:
  γ[mn-(m²+n²)/2]=-(γ/2)(m-n)²,
  ρ(∞)=Σ_n p_n(0)|n><n|,
  d<H>/dt=0。
いずれも上記文献から従う説明だが、逐次計算や極限の式は「補足」と明記すると出典区別が明快。

II. 定常状態、unitality、entropy (19:07–26:40)

II-1. 導入と定常状態 (19:07–21:40)
動画内容:
・開放系の entropy は非単調になり得る。では、entropy の非減少を保証する構造は何か、という問い (19:07–19:43)。
・定常状態は ℒ[ρ*]=0、すなわち dotρ*=0 (20:05–20:46)。
・閉鎖系ではエネルギー固有状態およびその混合が定常状態となり、von Neumann entropy は変化しない (21:00–21:32)。
文献照合: §3.2, (3.34)–(3.37), 印刷 p.50。
注意: 字幕の「エネルギー状態の任意の組み合わせ」は、異なるエネルギーの coherent な重ね合わせ一般を意味しない。正確には [H,ρ*]=0。縮退部分空間内の coherence は許される。

II-2. ユニタル写像 (21:54–24:59)
動画内容:
・unitality は unitarity と違う語。定義は Φ[1]=1 (21:54–22:17)。
・有限次元 d で最大混合状態 ρ_max=1/d は最大 entropy ln d を持つ。unital map ならこれが不変である (22:27–23:26)。
・時間独立 Lindblad generator では ℒ[1]=Σμ[Lμ,Lμ†]。従って unital iff Σμ[Lμ,Lμ†]=0 (23:38–24:50)。
・各 Lμ が自身の随伴と可換なら十分。各交換子が非ゼロでも和が打ち消される場合がある、と講師自身が訂正・補足する (24:31–24:50)。
・Hermitian な L はこの条件を満たす。L=√γ N はその例 (24:50–24:59)。
文献照合: §3.2, (3.38), (3.43)–(3.45), 印刷 p.51。
誤記を避ける点: 必要十分条件は「交換子の和がゼロ」であり「各 Lμ が Hermitian」ではない。さらに oscillator の Hilbert 空間は無限次元なので 1/d という正規化された最大混合状態は存在しない。この有限次元の定理を oscillator 全体へ無条件に当てはめない。

II-3. Entropy 非減少の定理 (25:05–26:40)
動画内容:
・講師は証明をしていないと明言 (25:09–25:12)。
・有限次元の unital CPTP map Φ に対して S(Φ[ρ])≥S(ρ) (25:12–25:47)。
・時間独立 unital CPTP semigroup なら任意の t2≥t1 に Φ_(t2-t1) を適用し S(ρ(t2))≥S(ρ(t1)) と解釈できる。
文献照合: 原文 §3.2 (3.45)–(3.50), 印刷 pp.51–52。
動画にない補足証明 (採用時は必ず明示・引用):
  τ=1/d,
  D(ρ||τ)=ln d-S(ρ),
  D(Φ[ρ]||Φ[τ])≤D(ρ||τ),
  Φ[τ]=τ より S(Φ[ρ])≥S(ρ)。
この証明は原文 (3.46)–(3.50) にある。relative entropy の data-processing inequality 自体の証明は原文でも省略している。
注意: ある初期時刻から各時刻までの写像が unital であることだけで時間に沿う単調性一般は結論できない。今回の semigroup 文脈なら中間写像も unital CPTP なので正しい。有限次元の条件を本文に残す。

III. SK 経路積分への移行 (27:18–44:59)

III-1. なぜ経路積分か (27:18–29:04)
動画内容:
・繰り込み、ゲージ理論、Wilsonian RG など QFT の課題には経路積分が便利。演算子形式と等価な形式を用意する (27:18–27:56)。
・SK の文献として Kamenev の本、operator の文献として Breuer–Petruccione に言及。両者を同じ規約で橋渡しするのが講義ノートの意図 (28:13–29:04)。
文献照合: 原文 Introduction “References and resources”; §4 冒頭。
注意: 発言をそのまままとめるなら書名の記憶違いを助長せず、書誌は原文 bibliography の Kamenev / Breuer 項目を使う。

III-2. SK が使われる三つの状況 (29:13–34:14)
動画内容:
・異なる分野で同じ SK が異なる目的に使われるため、前提や直観を確認する必要がある。
・(a) 純粋状態の Hamiltonian evolution、(b) 混合状態の Hamiltonian evolution（熱場の理論、保存的な流体力学など）、(c) 非 Hamiltonian evolution（本講義の開放系、散逸的流体力学等）を区別する (30:30–33:19)。
・熱密度行列は ρβ ∝ e^{-βH} (31:58–32:12)。正規化を書くなら Tr(e^{-βH}) で割る。
・この講義の「閉鎖系／開放系」は Hamiltonian / non-Hamiltonian evolution の区別。電荷保存の有無とは別問題 (33:47–34:14)。
文献照合: §4.1 冒頭 pp.62–63；Gibbs 正規化の式は (3.103) の量子ビット、または (3.135) の oscillator Gibbs state。
注意: 「純粋状態なら標準 in-out がいつでも同じ」という無条件な主張に広げない。講師は宇宙論での歴史的用法を口頭で簡略化している。短く SK は閉鎖系にも使える、と整理すれば忠実で正確。

III-3. 異時刻相関関数が動機 (34:35–35:27)
動画内容:
・ρ(t) と O から Tr(ρ(t)O) は直ちに計算できるが、異時刻、時間順序、反時間順序、retarded / advanced の相関関数を統一的に扱うには経路積分が便利。
・operator formalism で不可能なのではなく煩雑、と明言 (35:12–35:16)。
・まず単一時刻の簡単な演算子で導く (35:27–35:38)。

III-4. Trace から三つの位置積分へ (35:41–42:30)
動画内容:
  <O(t)> = Tr[U(t,t0)ρ0 U†(t,t0) O]
         = Tr[ρ0 U†(t,t0) O U(t,t0)].
・trace の巡回性で Schrödinger / Heisenberg の二つの表示が一致 (36:02–37:13)。符号 ±i[H,·] の違いもこれで確認できる。
・簡単のため一次元座標 x と O= xhat^n を使う。場 φ(x,t) への拡張は後で可能 (37:41–38:41)。
・1=∫dx|x><x| を 3 回挿入する (37:24–37:36, 38:45–39:10)。O は位置基底で diagonal なので、O の両側に独立に入れる必要がない。
復元したコンパクトな式:
  <xhat(t)^n> = ∫ dx_(+,0) dx_(-,0) dx_f
     ρ(x_(+,0),x_(-,0);t0)
     <x_f|U(t,t0)|x_(+,0)>
     <x_(-,0)|U†(t,t0)|x_f> x_f^n.
・x_(+,0), x_(-,0) は初期密度行列の二つの添字を区別するための名前。+ は第1添字、− は第2添字、0 は初期時刻 (41:25–42:06)。x_f は最終時刻の trace の位置変数 (42:10–42:30)。
・運動量を含む O についての質問には、p の identity resolution や <x|p> による同様の導出が可能と説明するが、今回の計算は xhat^n に限定 (39:12–39:40)。
文献照合: §4.1, (4.1)–(4.6), (4.10), 印刷 pp.62–64。
校訂注意: 原文 (4.6) に Schrödinger 位置 operator のはずの xhat(t)^n が trace 内に現れる表記の紛らわしさがある。本文では外側の期待値 <xhat_H(t)^n> と trace 内の固定演算子 xhat^n を区別するとよい。

III-5. 時間発展演算子と通常の経路積分 (43:18–44:59)
動画内容:
・経路積分は初期配置から最終配置への時間発展の行列要素を計算する (43:18–43:40)。
・時間独立 H なら U=e^{-iH(t-t0)}。時間依存 H(t) なら
  U(t,t0)=T exp[-i∫_(t0)^t ds H(s)] (43:43–44:14)。
・時間順序付き相関関数が自然なのは、時間発展自身が時間順序付きだから (44:14–44:30)。
・この通常の経路積分は t0 から t に向かう一つの経路である (44:36–44:59)。
  <x_f|U(t,t0)|x_(+,0)> = ∫_(x_+(t0)=x_(+,0))^(x_+(t)=x_f) Dx_+ e^{iS[x_+]},
  S[x]=∫_(t0)^t ds L(x,xdot).
文献照合: (4.4), (4.7)–(4.8), 印刷 p.63。
