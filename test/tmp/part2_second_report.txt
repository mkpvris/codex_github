1. 時間発展から二本の経路へ（45:04–47:45）
動画の内容：トレースの中に現れる U と U† の行列要素を、それぞれ通常の経路積分に置き換える。二つの積分変数を同じ x と書くと混乱するため x_+, x_- と名付ける。これが「場の倍加」だが、物理的自由度が新たに二倍になったわけではない（46:47–47:27）。
復元する数式：
  <x_f|U(t,t0)|x_{+,0}> = integral_{x_+(t0)=x_{+,0}}^{x_+(t)=x_f} D x_+ exp(i S[x_+])  (4.7)
  <x_{-,0}|U†(t,t0)|x_f> = integral_{x_-(t0)=x_{-,0}}^{x_-(t)=x_f} D x_- exp(-i S[x_-])  (4.9)
  S[x]=integral_{t0}^t dτ L(x,dot x)  (4.8)
重要な点：二つの積分とも履歴を t0→t の関数として記述でき、重みの符号が逆になる。後退枝という言葉は積分輪郭の向きを示す。
出典表示案：動画 45:04–47:27；数式は著者ノート §4.1, Eqs. (4.7)–(4.9) に照合。

2. 初期密度行列・終点の貼り合わせ・省略記法（47:51–55:40）
動画の内容：通常の積分 d x と履歴の経路積分 D x を明確に区別する（48:10–48:32）。初期の二つの値は密度行列によって重み付けされ、終点は二つの枝に共通な値を積分する。質問に答えて各経路の境界条件を再確認する（49:32–51:46）。52:01 以降はこれらを I.C. に省略する。
復元する数式：
  ρ(x_{+,0},x_{-,0};t0)=<x_{+,0}|ρ(t0)|x_{-,0}>  (4.10)
  <xhat(t)^n>=integral dx_{+,0} dx_{-,0} dx_f ρ(x_{+,0},x_{-,0};t0)
      × integral_{x_+(t0)=x_{+,0}}^{x_+(t)=x_f} D x_+ e^{iS[x_+]}
      × integral_{x_-(t0)=x_{-,0}}^{x_-(t)=x_f} D x_- e^{-iS[x_-]} x_f^n.  (4.11)
  x_+(t)=x_-(t)=x_f; 初期では一般に x_{+,0}≠x_{-,0}。
  <xhat(t)^n>=integral_IC D x_+ D x_- e^{iS[x_+]-iS[x_-]} x_±(t)^n.  (4.12)
I.C. は初期条件（Initial Conditions）。「整数」「密度行列の指数」などの字幕は採用せず、初期密度行列の行列要素による重みと書く。
三種の x を区別：量子演算子 xhat、可換な履歴 x_±(τ)、境界の積分変数 x_{±,0},x_f。
最終時刻の単一挿入では ± をどちらに置いても同じ。異なる時刻への挿入では枝の指定が必要（54:14–54:38）。
出典表示案：動画 47:51–55:40；著者ノート §4.1, Eqs. (4.10)–(4.12)。

3. 外部源と生成汎関数（55:47–58:11）
動画の内容：演算子ごとに別の経路積分を計算する代わりに、J_+(t), J_-(t) を導入する。これらは任意に指定する外部関数であり、源による汎関数微分で x_± の挿入を生成する。両枝の源が等しければ Z[J,J]=1（57:24–57:59）。58:07 にマイナス符号を確認している。
復元する数式：
  Z[J_+,J_-]=Tr[U_{J_+} ρ0 U_{J_-}†], U_J=T exp[-i integral (H-J xhat)dt].  (4.13),(4.14)
  Z=integral_IC D x_+ D x_- exp{iS[x_+]-iS[x_-]+i integral dt[J_+x_+-J_-x_-]}.  (4.18)
  (1/i) δ/δJ_+ inserts x_+; -(1/i) δ/δJ_- inserts x_-; evaluate sources at zero.
  Z[J,J]=Tr ρ0=1.  (4.22)
補足として追加するなら明記：演算子表示から U_J†U_J=1 とトレース巡回性で最後の恒等式を導く。著者ノート §4.1, Eqs. (4.13),(4.22)。
字幕に「J+をいくつでも得る」とあるが、生成するのは x_± の挿入。

4. in–out との関係と輪郭順序（58:50–1:09:42）
動画の内容：58:50–59:55 は休憩後の質疑への回答。ミンコフスキー時空の真空・ユニタリ発展では通常の in–out 法との関係があるというコメントで、証明はしていない。広い意味で『あらゆる SK 相関関数が通常の時間順序積そのもの』とは書かない。
1:00:45–1:02:18：<O>=Tr(ρ O) と経路積分平均 <<F[x_+,x_-]>> の記号を区別。二本の枝の c 数を非可換な演算子と混同しない。
1:02:31–1:05:43：経路積分は輪郭順序を計算する。+枝だけなら時間順序、−枝だけなら反時間順序、別々の枝なら Wightman 関数になる。
1:06:09–1:08:02 の四つの二点関数（とくに 1:07:20 以降に左右を再確認している）：
  <<x_+(t)x_+(t′)>> = <T xhat(t)xhat(t′)>  (4.26)
  <<x_-(t)x_-(t′)>> = <Tbar xhat(t)xhat(t′)>  (4.27)
  <<x_+(t)x_-(t′)>> = <xhat(t′)xhat(t)>  (4.28)
  <<x_-(t)x_+(t′)>> = <xhat(t)xhat(t′)>  (4.29)
−枝は輪郭上で必ず +枝より後にあるため、演算子積では左に置かれる。『+が先』は輪郭上の順序を意味し、通常の時刻の大小ではない。
一般式：
  << product_i O_+(ti) product_j O_-(tj) >>
    = < Tbar[product_j O(tj)] T[product_i O(ti)] >.  (4.30)
1:08:33–1:09:24：より一般の OTOC には追加の往復枝を持つ輪郭が必要になる場合がある。二枝 SK ですべての任意順序の多点関数が直接得られるとは書かない。
1:09:27–1:09:42：複素時間輪郭の虚部は下方に進むという iε に関する短い助言。証明・一般的条件は講義中にはないので、詳細化しないか明示的な補足文献を付ける。
補足として追加するなら明記：折り返し時刻 tf を最後の挿入より遅く置けば、余分な前進・後退は打ち消す (4.23)。詳細な導出は著者ノート §4.2 の「Turn-around point」。

5. Keldysh（r/a）基底（1:09:48–1:16:15）
動画の内容：平均と差の変数へ基底変換し、その二点関数により揺らぎと応答を見通す。
  x_r=(x_++x_-)/2, x_a=x_+-x_-; x_±=x_r±x_a/2.  (4.31),(4.32)
1:10:24–1:10:49：r/a を retarded/advanced と呼び、classical/quantum という呼称は本講義では用いない。基底の発見年や命名逸話は字幕が不確か（1974 と聞き取られている）なのでノート本文には不要。
1:12:09–1:12:37：rr は演算子反交換子。係数は (1/2)。1:16:06 に講師が 1/2 を追記している。自動字幕だけでその直前の先進関数に 1/2 を付けない。
厳密に採用する式：
  G_K(t,t′):=<<x_r(t)x_r(t′)>>=(1/2)<{xhat(t),xhat(t′)}>  (4.38)
  G_R(t,t′):=<<x_r(t)x_a(t′)>>=θ(t-t′)<[xhat(t),xhat(t′)]>  (4.39)
  G_A(t,t′):=<<x_a(t)x_r(t′)>>=θ(t′-t)<[xhat(t′),xhat(t)]>  (4.40)
  <<x_a(t)x_a(t′)>>=0.  (4.41)
  G_A(t,t′)=G_R(t′,t).
この講義・著者ノートの定義は G_R,G_A に -i を含めない。通常の場の理論で -i を含める規約もあるが、その場合には定義を明示し、この講義の式に黙って混ぜない。ar の交換子の順序は ra と逆である。
最大の字幕トラップ：1:13:02『A場を一つでも含んでいればゼロ』はそのまま採用してはならない。ra が非零なので矛盾する。正しい一般化は
  <<x_a(t1)...x_a(tn)>>=0 (n≥1), すべての挿入が a のとき。  (4.46)
動画 1:12:52–1:13:53 でこの aa 消失と全次数への一般化を説明している。著者ノート §4.2 の明記で補正する。
1:14:31–1:15:27：混合相関は θ 関数×交換子となり、r の時刻が a より後の因果的応答を表す。古典物理の遅延応答とのつながりを強調。
補足としてのみ追加できる内容（動画では詳細未導出）：
  Jr=(J_++J_-)/2, Ja=J_+-J_-, J_+x_+-J_-x_-=Ja xr+Jr xa.  (4.42)–(4.44)
  Z[Jr,Ja=0]=1 を Jr で微分して a のみの相関の消失を導く。§4.2, (4.45),(4.46)。
  1 個の r と残り a の多点相関が入れ子の交換子になる詳細式は (4.48)–(4.50)。動画では『全次数で成り立つ』というコメントに留まり、詳細式を主講義本文として書かない。

6. 環境の積分消去と影響汎関数（1:16:15–1:25:44）
1:16:15–1:17:03：ここまでの SK は閉じたハミルトニアン系。SK を導入しただけで散逸が生じるのではないことを再確認する。
1:17:27–1:18:28：追跡する自由度 x と追跡しない環境 q に分ける。
  S_tot[x,q]=S_S[x]+S_E[q]+S_int[x,q].  (4.52)
1:18:45–1:20:43：両枝の q_± を積分し、x_± だけに依存する影響作用 S_IF（講師は影響汎関数と呼ぶ）を定義。
  e^{i S_IF[x_+,x_-]} := integral_{ρ_E(t0)} Dq_+ Dq_-
      exp{i S_E[q_+]-i S_E[q_-]+i S_int[x_+,q_+]-i S_int[x_-,q_-]}.  (4.55)
1:21:08–1:22:08：系だけの生成汎関数は
  Z=integral_{ρ_S(t0)} Dx_+ Dx_- exp{i S_S[x_+]-i S_S[x_-]+i S_IF[x_+,x_-]
       +i integral dt (J_+x_+-J_-x_-)}.  (4.56)
  S_eff=S_S[x_+]-S_S[x_-]+S_IF[x_+,x_-].  (4.57)
境界条件を無言で失わないため、環境の最終値も q_+(tf)=q_-(tf) と貼り合わせ、その値をトレースしていると説明する。
上の簡潔な ρ_S,ρ_E 分離には因子化初期状態 ρ_SE(t0)=ρ_S(t0)⊗ρ_E(t0) が必要。講義字幕ではこの仮定を明示していないので、追加する場合は「文献に基づく補足」として §4.3, Eq. (4.54) を引用する。初期相関のある一般の場合には初期重みが一緒に残る。
1:22:24–1:23:54：閉じた系の作用は +枝だけの関数と −枝だけの関数の差。環境の +/− の相関を介して q を消去すると x_+ と x_- を結ぶ枝間相互作用が生じ、還元された力学の非ユニタリ性を表現する。『枝間相関があるだけで開放系』とは書かない。閉じた系にも Wightman 相関はある。ここで新しいのは有効作用の枝間相互作用。
1:24:15–1:25:27：講師は S_IF=0 を閉じた系、S_IF≠0 を開いた系と模式的に対比し、散逸・雑音・記憶効果を列挙する。1:25:14–1:25:21 で繰り込みにも触れるが『今は忘れて』と断る。
厳密化の補足（必要なら §4.3 を引用）：非零 S_IF のすべてが非ユニタリとは限らず、δS[x_+]-δS[x_-] 型の実局所項はハミルトニアンのパラメータ補正に吸収できる。開放系特有の構造はそのように分離できない枝間結合などにある。これは動画の説明を正確にするための著者ノートに基づく補足として分離する。
講義の範囲はここで終了。SK の三制約、Gaussian 環境の詳細、Langevin 方程式等（原稿 §4.4 以降）はこの動画の後半には登場しないので、後続講義を先取りした本文にはしない。
