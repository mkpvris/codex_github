概要
Feynman と Vernon の影響汎関数法を、任意の温度における Brownian 運動の研究に適用す
る。対象とする系と環境との散逸的相互作用について特定の模型を選ぶことにより、影響汎関数
を閉じた形で評価し、現象論的な粘性係数など少数のパラメータで表すことができる。¯h → 0 の
極限では、影響汎関数の形式から得られる結果が古典的な Fokker–Planck 方程式に帰着するこ
とを示す。任意の強さの減衰を受ける単純調和振動子の場合には、任意の温度で、系がある特定
の種類の純粋状態から出発するときの完全な密度行列 ρ(x, x′, t) の時間発展を明示的に表す式を
得る。得られた結果を、量子力学における散逸の問題に対する他の方法の結果と比較する。

1 序論
自然界には、古典的な領域では次の形の運動方程式によって十分に記述できる系が数多く存在
する。
m¨x + η ˙x + v′(x) = F (t). (1.1)
これは、例えば粘性流体中に浸されたコロイド程度の大きさの粒子を表すことができる。この場合、
m は粒子の質量、η は減衰定数、v(x) は粒子に作用するポテンシャルであり、F (t) はいわゆる揺動
力である。この力は
⟨F (t)⟩ = 0,
⟨F (t)F (t′)⟩ = 2ηkT δ(t − t′) (1.2)
という関係に従う。ここで ⟨ ⟩ は、同じように準備された系の集団についての統計平均を表す。関
係 (1.2) を満たす式 (1.1) は、よく知られた Langevin 方程式であり、すでに半世紀以上にわたって
Brownian 運動の理論の基礎として用いられてきた [1]。
他のあらゆる現象論的方程式と同様に、式 (1.1) の有効範囲は限られている。系の長時間での振る
舞いに関心がある場合には、Langevin 方程式を用いるのが妥当である。ここで長時間とは、対象と
する系に結合した熱浴の緩和時間に比べて長い時間を意味する。先に挙げた例では、粘性媒質中の巨
視的粒子は古典論によって十分に記述できるため、量子効果を気にする必要はない。しかし、他の多
くの場合には事情は異なる。例えば LCR 回路を考えると、コンデンサーの極板上の電荷についての
方程式は式 (1.1) の形をとることが分かっている。温度が非常に低くなると、この系で量子効果が観
測されると予想される。したがって、減衰を含む運動方程式と量子化の手続きをどう両立させるか、
という極めて自然な問題が生じる。
この問題の起源は、標準的な量子化の手続きが、対象とする系について Hamiltonian または
Lagrangian 関数のいずれかが存在することに基づいているという事実にある。 一方、 陽に時間に依存
しないいかなる Lagrangian または Hamiltonian にも、 古典的なLagrange 方程式または Hamilton
方程式を適用して式 (1.1) を得ることはできないことがよく知られている。時間に依存する関数を用
いれば、標準的な量子化の手続きを直接利用することはできる [2]。しかし、この方法では不確定性
原理に関する幾つかの問題に直面せざるを得ない [3]。過去 20 年から 30 年にわたり、多くの人々が
この問題に答えようとしてきた。用いられた方法は多様であるが、これらの試みはすべて二つの主要
な範疇に分かれる。すなわち、新しい量子化の方式を探すか、あるいは系と熱浴を合わせて扱う方法
を用いるかである。以下では、それぞれの範疇における比較的重要な研究の一部を挙げる。
1970 年代の初めに、 Kostin[4] は非線形 Schrödinger 方程式を用いた理論を提案した。この理論
は重ね合わせの原理に反するだけでなく、定常的な減衰状態のような、非常に議論の多い結果も示
す。Nelson の確率量子化 [5] に基づいて、K. Yasue[6] は Kostin の方程式を導いた。これが可能な
のは、Nelson の量子化では Hamiltonian や Lagrangian の代わりに運動方程式そのものを知ればよ
いからである。ここでの主要な問題は、Nelson の理論が正しいかどうかということである。
Dekker[7] は、複素変数を用いる正準量子化の手続きを開発した。密度演算子の Wigner 変換に対
する Fokker–Planck 方程式など、幾つかの興味深い結果を再現するにもかかわらず、この理論には
3
不明瞭な点がある。例えば、彼は位置 x(t) の方程式に陽な雑音源を導入し、さらに運動量の方程式
にも別の雑音源を導入している。そのようにする物理的な理由は見いだせない。 Dekker の研究にお
ける幾つかの点には後で立ち戻る。
われわれの知る限り、これまでに最も成功している方法は Senitzky[8] の研究によって切り開かれ
たものである。そこで彼は、対象とする系と熱浴との相互作用を陽に考慮した。その研究では、特に
共振器内の電磁場モードの減衰を扱っている。彼の方策は、熱浴の演算子を消去することによって
Heisenberg 描像で実行される。この理論は後に Mori[9] によって一般化された。同じ方向に沿って、
Zwanzig[10] と Nakajima[11] は Schrödinger 描像で研究し、密度演算子に対する一般化されたマス
ター方程式を得た。この種の方法についての優れた総説は文献 [12, 13] にある。

本論文で採用する一般的な方法は、文献 [8, 9, 10, 11, 12, 13] の研究と多くの共通点を持つ。すな
わち、散逸系それ自体を量子化することは試みず、初めから複雑な環境と相互作用するものとして扱
う。まさにこの相互作用が散逸を生じさせるのである。系と環境からなる完全な「宇宙」は閉じたも
のとして扱うことができるので、それに標準的な量子化の手続きを適用することには、もちろん何の
支障もない。その後、環境の座標を消去し、散逸系だけについて閉じた方程式を得る。この消去を行
うには、当然ながら系と環境との相互作用について十分に単純な模型を選ばなければならない。さら
に、その模型は古典的な高温極限で古典的な Brownian 運動の結果を再現するように構成されてい
なければならない。
関連した問題を研究した論文は数多い。Ford ら [16] は、二次のポテンシャルを通じて互いに相互
作用する同種粒子の列を研究した。そのうちの一つに着目し、古典的な領域でそれをBrownian 粒子
として振る舞わせるには、粒子間ポテンシャルがどのような形でなければならないかを調べた。Iche
と Nozières[17] は、環境中の重い粒子について断熱展開を構成したが、得られた結果は主として形
式的なものである。
Davies[18] は、系の粒子の拡散的な振る舞いや、Markoff型の Fokker–Planck 方程式などについ
て、幾つかの優れた厳密な結果を証明した。しかし、それらが成り立つのは、減衰が極めて弱い場合
だけである。Schwinger[19] は、熱浴に弱く結合した量子振動子の運動に自身の作用原理を適用し、
振動数のずれと一定の減衰という問題を注意深く研究した。

本論文の目的は、質量や摩擦係数など、原理的には実験で測定できる現象論的パラメータだけを含
む、散逸的な量子力学系の閉じた方程式を、どこまで得られるかを調べることである。このために、
系と環境との相互作用について特定の模型を設定し、適切な極限で Brownian 運動の古典的方程式
を再現するという条件から、模型のパラメータを定める [20]。その上で、より一般的な場合、例えば
量子的な場合に何が導かれるかを調べる。密度行列の伝播関数について、相互作用のない場合にすで
に現れる式よりもわずかに複雑なだけの一般的な形式的表式を、汎関数積分の形で書き下せることを
示す。また、調和振動子という特殊な場合には、任意の減衰の強さと任意の温度について、それを明
示的に評価できることを示す。応用として、ある種類の純粋状態から出発する減衰調和振動子の時間
発展を明示的に研究する。一貫して用いる手法は、量子力学の汎関数積分による定式化であり、より
具体的には Feynman と Vernon の「影響汎関数」の手法である。
この研究の当初の動機は、ポテンシャル障壁を通り抜ける量子力学的トンネル現象に対する散逸の
効果を理解したいということであった。汎関数積分法そのものはこの問題に非常によく適している
が、本論文で展開する特定の方法はそうではないことが分かった。逆に、トンネル問題に最も適した
方法、すなわち「虚時間」表示を用い、4 点関数ではなく 2 点関数を考える方法は、古典的に到達可
能な領域での系の時間発展を論じるのにはあまり適していない。この理由から、文献 [21] に示した
トンネル問題の扱いとは、本論文の議論を分けるのが妥当であると考える。それでも両者に共通する
問題は多く、特に散逸機構についてのわれわれの模型の一般性と現実性の程度、および速度に依存す
る結合によって生じる修正がそれに当たる。こうした問題の一部は文献 [21] でさらに詳しく論じて
いる。したがって本論文の各所で、この研究を相互参照する。
第 2 節では、影響汎関数の Feynman–Vernon 理論 [22, 23] を概説する。第 3 節と第 4 節では、熱
浴の具体的な模型について影響汎関数を評価する。これによって、適切な状況でのBrownian 粒子の
縮約密度演算子の伝播関数が得られる。第 5 節では、量子的な表式の ¯h → 0 の極限を調べることに
より、Brownian 運動の古典的方程式を再現することを扱う。第 3 節と第 4 節の結果の応用を第 6 節
に示す。特に、時刻ゼロにおいて Gaussian 型の、必ずしも最小不確定性ではない純粋状態の波束で
記述される減衰調和振動子を考え、その後のすべての時刻について密度行列を明示的に計算する。最
後に第 7 節で結論を述べる。

3 模型
原理的には問題は解けている。式 (2.3) と (2.4) の粒子間ポテンシャル vi(x, Ri) と vB(Ri, Rj)、
および ρB(0) で記述される熱浴の初期状態が分かれば、式 (2.16) の影響汎関数を求めることができ

る。しかし、経験から分かるように、現実はそれほど単純ではない。多体系の分野で厳密に解ける問
題はごく少ない。問題を完全に一般的なまま厳密に解けると考えるのは望みがない。必要なのは、構
成上解くことのできる特定の模型を用いることであり、それから、多くの他の系にも拡張できると考
えられる幾つかの一般的な結論を引き出すことを期待する。

て w(p, x, t) は古典的な位相空間分布に近づく。したがって、 ¯h → 0 のとき、式 (5.14) は古典的な
Brownian 粒子の位相空間分布の時間発展を記述すると結論できる。
また、式 (5.14) の右辺第三項は、式 (3.38) の指数の虚部に γ に依存する項が存在することの直接
の帰結であると分かる。したがって、この項が Brownian 粒子の古典的運動方程式に η ˙x の形の力を
出現させる原因である。
ここまでで得られたのは、伝播関数 J に対する我々の量子力学的な式 (3.38) が、Brownian 粒子
の古典的運動を記述すると考えられている方程式と完全に整合するということである。またこれは、
式 (3.23) における ρD(ω)C 2(ω) の選択が非常に適切であり、現象論的な減衰定数 η だけを用いて J
を記述できることも意味している。

7 結論
熱浴と相互作用する粒子の具体的な模型を用いて、その粒子の縮約密度演算子の伝播関数に対す
る式 (3.38) を導いた。前節で示したように、ある状況では、任意の時刻 t、あらゆる温度における
˜ρ(x, y, t) の閉じた式を得ることができた。 波束˜ρ(x, x, t) の中心は古典的な Brownian 粒子の運動に
従い（式 (6.33) を参照） 、その無限時間極限における幅は揺動散逸定理(6.35) と一致することを示し
た。後者の結果について、もう少し詳しく考察できる。
まず、式 (6.35) は文献 [27] と一致しない。そこでは、自由粒子の波束の幅は無限時間で「凍結す
る」と主張されている。式 (6.35) で ωR → 0 とすると、T → 0 のとき、式 (6.35) は ν → 0 におい
て (− ln ν) のように発散することを示せる。これは、t → ∞ のとき σ2(t) が ln t のように振る舞う
ということに等しい。したがって、σ2(t) の広がりは減衰がない場合（σ2(t) =
√
A + Bt2）より遅い
が、凍結することはない。
我々は、両者の方法のこの相違は、我々と異なり文献[27] の著者たちがいかなる拡散効果も考慮し
ていないことに起因すると考えている。式 (6.1) で ϕ[x, y] = 0 とすることにより、二つの方法の物
理的解釈が全く異なるにもかかわらず、彼らの結果を再現できる。

式 (7.2) の形の拡散定数は Papadopoulos[28] と Svin’in[38] によって提案されている。 しかし、 こ
こでも、彼らの理論が有効なのは弱い減衰の極限だけである。これは、その式が成り立つための必要
条件だからである。
実際、量子的領域においてさえも、Markoff型の方程式（時間核を含まないもの）で平衡への緩和
を記述しようとすることは、多くの物理学者にとって長年の夢であった。しかし、我々はその可能
性にやや懐疑的である。我々が示したように、簡単な模型でも、全く Markoff型でないまま、平衡
統計力学と線形応答理論の両方を漸近的に再現できるためである。 Ford ら [16] も、量子極限におけ
る Markoff型という仮定について同じ結論に達している。ここで論じているのは拡散項だけである
ことに注意されたい。我々のドリフト項（ γ を含む項）は常に Markoff型である。後者に対する非
Markoff型の補正を求めるには、Brownian 粒子の短時間の振る舞いを記述するのに重要な総和則に
よる χ′′(ν) の修正を調べる必要がある。

けるのは振動数のずれ (∆ω)2 だけであり、いずれにせよ、これは直接には観測できない（トンネル
問題における類似の点についての文献 [21] の議論を参照） 。
