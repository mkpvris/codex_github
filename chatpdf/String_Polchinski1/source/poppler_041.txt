The field Y − does not appear in any terms with time derivatives and
so is nondynamical. It acts as a Lagrange multiplier, constraining ∂σ2 γτσ
to vanish (extra ∂σ because Y − has zero mean). Note further that in the
gauge (1.3.8) the open string boundary condition (1.2.28) becomes
                       γτσ ∂τ X µ − γττ ∂σ X µ = 0            at σ = 0, + .                      (1.3.13)
For µ = + this gives
                                      γτσ = 0        at σ = 0, +                                 (1.3.14)
and since ∂σ2 γτσ = 0, then γτσ vanishes everywhere. For µ = i, the boundary
condition is
                                 ∂σ X i = 0          at σ = 0, + .                               (1.3.15)
