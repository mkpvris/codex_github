   There is an anomaly in the gauge symmetry when cm -= 26, so we
expect some breakdown in the BRST formalism. The BRST current is
still conserved: all of the terms in the current (4.3.3) are analytic for any
value of the central charge. However, it is no longer nilpotent,

                         {QB , QB } = 0 only if cm = 26 .                            (4.3.9)
