   We often need the asymptotic behavior of the theta function as q → 0
or as q → 1. The q → 0 behavior can be read immediately from either the
infinite sum or infinite product form. The q → 1 behavior is not manifest
in either form, because an infinite number of terms contribute. It can be
obtained from the τ → −1/τ modular transformation, which relates these
two limits by q → exp(4π 2 / ln q).
