   Using the relation (9.1.28), the form and normalization of eq. (9.1.26)
agree with the unitarity condition (9.1.24), leaving one important loose
end. The sum in the unitarity relation runs only over the physical Hilbert
space, the BRST cohomology, while the final sum in (9.1.28) runs over a
complete basis for Ĥ. We now show that these sums are equal. Consider
the following basis for Ĥ. First, take a complete set of ‘unphysical states’
|a&U . That is, no linear combination of these is annihilated by QB . Second,
take a complete set of BRST-invariant states |b&P which are independent
in the sense that no linear combination of them is null. Finally, take the
complete set of BRST-null states |a&N = QB |a&U to complete the basis.
Define the operators P and U:
                        P|b&P = |b&P , P|a&U = 0 , P|a&N = 0 ;                       (9.1.30a)
                        U|b&P = 0 , U|a&U = 0 , U|a&N = |a&U .                       (9.1.30b)
Then
                                    1 = P + QB U + UQB .                              (9.1.31)
Insert this decomposition into the factorization relation. The first term
projects onto one state from each cohomology class, the physical spectrum
appearing in the unitarity sum. The second and third terms each contain
QB , and so vanish by the earlier argument that null states decouple. Thus
unitarity is established.
