                                 Backgrounds
One other qualitative feature of the field equations is readily understood:
the field Φ always occurs di!erentiated, so there is an invariance under
X µ -independent shifts of Φ. This is because such a shift only changes the
world-sheet action (3.7.6) by a term proportional to the Euler number,
and so does not a!ect local properties like Weyl invariance. In particular,
the background
               Gµν (X) = ηµν ,    Bµν (X) = 0 ,   Φ(X) = Φ0            (3.7.16)
is exactly Weyl-invariant for any constant Φ0 . This is just the flat spacetime
action (3.2.2), with
                                   λ = Φ0 .                            (3.7.17)
The value of λ determines the coupling strength between strings, but we
now see that this does not mean that there are di!erent string theories with
di!erent values of this parameter. Di!erent values of λ correspond not to
di!erent theories, but to di!erent backgrounds in a single theory. The other
parameter appearing in the Nambu–Goto and Polyakov actions, the Regge
slope α$ , is also not really a free parameter because it is dimensionful. It
simply defines the unit of length, and can be absorbed in the definition of
X µ.
   Changing the fields Gµν , Bµν , and Φ in the world-sheet action would
seem, from the two-dimensional point of view, to give a new theory.
From the point of view of the full string theory, one is merely looking
at a di!erent background — a di!erent state — in the same theory.
