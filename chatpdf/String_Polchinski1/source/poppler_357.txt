Euclidean path integrals are usually the more well-defined, because the ex-
ponential of the action is damped rather than oscillatory. The Minkowski
matrix elements can then be obtained by analytic continuation. In the
text our main concern is the Euclidean path integral, which we use to
represent the string S-matrix.
