ﬁeld       Mij        can           be           diagonalized,           by           aU(1)×          U(1)           rotation,           and           the           potential
is               ﬂat               when               exactly               one               diagonal               element               is               nonzero.               Now,               however,               the

potential.                 That                 string                 theory                 on                 an                 orbifold                 can                 be                 equivalent                 to                 string
