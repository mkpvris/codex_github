                                                                                  3.1                                             Sums               over               world-sheets

The                  Feynman                 path                  integral                  is                  one                  way                  to                 represent                  a                  quantum                  theory,
and           it           is           a           very           natural           method           for           describing           interactions           in           string           theory.
In               path               integral               quantization,               amplitudes               are               given               by               summing               over               all
possible                histories                interpolating                between                the                initial                and                ﬁnal                states.                Each
history             is             weighted             by

with               Scl         the              classical              action              for              the              given              history.              Thus,              one              would              deﬁne
an          amplitude          in          string          theory          by          summing          over          all          world-sheets          connecting

ﬁgure               3.1(b)               for               the               closed               string.               The               analogous               sum               for               the               relativistic
point             particle             produces             the             free             propagator             (exercise             5.1).
