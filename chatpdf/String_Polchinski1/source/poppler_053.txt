In the following exercises one has the usual open or closed string boundary
conditions (Neumann or periodic) on X µ for µ = 0, . . . , 24 but a di!erent
boundary condition on X 25 . Each of these has an important physical
interpretation, and will be developed in detail in chapter 8. Find the mode
expansion, the mass spectrum, and (for the closed string) the constraint
from σ-translation invariance in terms of the occupation numbers. In
some cases you need the result of exercise 1.5.

1.7 Open strings with
                     X 25 (τ, 0) = 0 ,      ∂σ X 25 (τ, +) = 0 .
This is an open string with one end on a D-brane and one end free.
1.8 Closed strings with
                     X 25 (τ, σ + +) = X 25 (τ, σ) + 2πR
with R a constant. This is a winding string in toroidal (periodic) compact-
ification. In this case p25 must be a multiple of 1/R.
1.9 Closed strings with
                          X 25 (τ, σ + +) = −X 25 (τ, σ) .
This is a twisted string in orbifold compactification.
